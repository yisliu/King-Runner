# King-Runner

This is an infinte runner game where you play as a King who runs in a medival inspired environment.

## About

King-Runner is 3D infinite runner while following a tutorial. This game was the first main project in my game development journey and taught me how to create an infinite runner.

## Status

This is the tutorial based version of King-Runner, but I have applied what I learned from this project to make my own infinite runner called Island Infinite.

## Built With

- Unity 3D
- DOTween
