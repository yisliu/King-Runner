# Whisker — Design Document

## Concept

This game is an infinite runner where the player plays as a King that runs through different road chunks that have a medival inspired environment. The game ulitizes both moving obstacles and static obstacles to challenge the player. The player can pick up an apple to speed up and coins for points.

## How to Play

The game starts when the player runs it. They can control the King by using the A and D keys to travel left and right.
